TFLite on Linux even when ONNX is selected. The versioned uv override omits it
on Python >=3.12; actual ONNX inference works, but generic uv pip check flags
that upstream-declared requirement. This remains a Pi compatibility gate, not
an unmodified dependency pass. Official inference assets/URLs/computed hashes
and license notes are stored in var/cache/wake/openwakeword-v0.5.1/.

AEC execution, neural noise enhancement, actual Pi input/output, real-speaker
wake/VAD qualification and acoustic interruption remain unverified. Generated
configurations use placeholder nodes. No global SOTA ranking, hardware sufficiency
or echo-removal claim follows from these CPU/synthetic tests.
