# Archived Compact-Publication Proposal

The original metadata-archive proposal is retained at
[commit 9de6bb4](https://github.com/ercallagon/ai231/blob/9de6bb4eb0bf309b1166969748875e3d78cb49e7/me2-vcm/docs/compact-publication.md).
It predates the curated publication and is not a required download step.

The current tree contains permitted manifests, frozen VCM ONNX files, selected
checkpoints and training logs. No separate metadata-release archive is needed
for the documented [reproduction command](../README.md#one-command-result-reproduction).
The historical `prepare_compact_publication.py` helper remains for provenance;
it does not define current installation, selected models or release readiness.

Use the [documentation index](README.md), [dataset terms](../data/DATASET_LICENSE.md)
and [model terms](../MODEL_TERMS.md) for the current workflow and access limits.
